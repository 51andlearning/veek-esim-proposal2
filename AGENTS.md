# Slide heading rule

No slide heading, in pptx or html, may have more than 3 words. This covers every slide title, section heading and metrics heading in every deck, proposal, pitch, report or site with slides. Count words after removing ** markers and punctuation. Put figures in the body, not the heading. Check every heading before you commit or publish. (Edward Wicks, 2 November 2026.) If a heading genuinely needs more than 3 words, ask Edward before using it. In an unattended run, use a 3 word heading and add a Decision item on the Approvals page with the longer wording for Edward to approve.
